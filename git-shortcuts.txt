GIT SHORTCUTS FOR DUMMIES

1. BASIC COMMANDS

1. pwd = tells you your current location.
2. git init = initializes an empty repository.
3. mkdir git-Notes = creates a directory (folder).
4. cd git-Notes = enters the folder.
5. touch file-name = creates an empty file.
6. ls = shows the files inside the current directory.
7. ls -la = shows all files, including hidden files.
8. cd .. = goes back one step (parent folder).

2. CHECKING AND SAVING CHANGES

9. git status = checks for changes.
10. git add . = stages all changes within the current directory and its subdirectories.
11. git add file-name = stages only one file.
12. git commit -m "comment" = commits (saves) the staged changes.
13. git log --oneline = shows a short summary of commit history.
14. git diff = shows unstaged changes.
15. git diff --staged = shows staged changes.

3. UNDOING CHANGES AND DELETING FILES

16. git reset --soft HEAD~1 = undoes the last commit but keeps changes staged.
17. git reset HEAD~1 = undoes the last commit but keeps changes unstaged.
18. git rm file-name = deletes a file and moves its deletion directly to the staging area.
19. git rm --cached file-name = stops tracking a file but keeps it on your computer.
20. git reset --hard HEAD = discards all uncommitted changes and restores tracked files to the latest commit.
21. git restore file-name = restores the last committed version of a file if it has unstaged changes or was deleted.
22. git restore --staged file-name = unstages a file but keeps its changes.

4. BRANCHES

23. git branch = shows all local branches.
24. git branch branch-name = creates a new branch.
25. git checkout branch-name = switches to an existing branch.
26. git merge branch-name = merges the specified branch into your current branch.
27. git branch -d branch-name = deletes a branch if it has already been merged.

5. COMPARING CHANGES

28. git diff commit-ID-1 commit-ID-2 = shows the differences between two commits.
29. git show commit-ID = shows the details and changes of a specific commit.

6. GITHUB AND REMOTE REPOSITORIES

30. git clone URL = downloads a repository from GitHub to your computer for the first time.
31. git push = uploads commits from your local repository to GitHub.
32. git pull = brings changes from GitHub to your local repository.
33. git fetch = downloads updates from GitHub without merging them into your current branch.

7. GIT STASH

34. git stash = temporarily saves unfinished tracked work without committing it.
35. git stash pop = brings back your latest stashed work and removes it from the stash list if successful.
36. git stash apply = brings back stashed work but keeps it in the stash list.
37. git stash list = shows all saved stashes.
38. git stash drop = removes a stash manually.

8. REVERT AND REBASE

39. git revert commit-ID = reverses changes from an old commit by creating a new commit.
40. git rebase main = replays your current branch's commits on top of the latest main branch.
